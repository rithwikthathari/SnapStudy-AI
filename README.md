# 📚 SnapStudy AI

SnapStudy AI is an AI-powered study assistant built using Streamlit and Gemini Vision.

It helps students understand questions, diagrams, textbook pages, and handwritten notes by simply uploading an image or typing a question.

## ✨ Features

- 📸 Upload images of questions, diagrams, or notes
- 🤖 AI-powered image understanding using Gemini
- 🧠 Step-by-step explanations
- 💬 Ask follow-up questions
- 📝 Generate a summary of the study conversation
- 📧 Send study notes to email
- 🎓 Simple and student-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Gemini Vision
- Gmail SMTP
